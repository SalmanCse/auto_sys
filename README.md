IoT-Based Humidity Automation System

This project presents a research-oriented IoT automation system for precise measurement, monitoring, and regulation of ambient humidity. It leverages DHT11/DHT22 sensors connected to microcontrollers such as ESP8266, Arduino, and Raspberry Pi to collect accurate environmental data for analysis and automated control.
The sensor data is transmitted to a web-based interface developed in PHP, while MySQL provides robust and secure data storage. The system supports intelligent automation, enabling dynamic adjustments of environmental conditions based on real-time feedback.

Features
Real-time monitoring: Continuous measurement of humidity levels for accurate tracking.
Automated control: Humidity is regulated automatically based on configurable thresholds.
Multi-platform support: Works with ESP8266, Arduino, and Raspberry Pi microcontrollers.

Data management: MySQL database enables structured storage and historical analysis.

Web-based visualization: PHP interface allows remote monitoring, reporting, and control.

Applications
Smart homes and office environments
Greenhouses and agricultural monitoring
Laboratories and sensitive equipment facilities
Any setting requiring precise humidity regulation
Technology Stack

Sensors: DHT11, DHT22

Microcontrollers: ESP8266, Arduino, Raspberry Pi

Backend & Database: PHP, MySQL

Communication: Wi-Fi / IoT protocols
